# HTML Demo Comments Storage

> **Live Demo Backend**: Dedicated storage repository for the [Markdown Comments Plain HTML Live Demo](https://md-comments.com/demo-html/).

---

## 🎯 Purpose of This Repository

This repository exists **exclusively** to store live comment data from public HTML interactive demo instances in a dedicated orphan Git reference:

```
refs/md-comments/data
```

### Key Details & Privacy Policy:
1. **Zero Branch Commits:** No comments or files are committed to standard Git branches (`main`).
2. **Ephemeral 24-Hour Retention:** All comment threads in `refs/md-comments/data` are **automatically wiped every 24 hours at 00:00 UTC** via an automated GitHub Actions cleanup workflow to keep the environment clean and ensure no permanent data/PII retention.
3. **No Code / No Pull Requests:** This repository is an automated data store for the live demo. Pull requests and issues are disabled.
